# J11 Trener

Fotballapp for J11-lag — spilletid, bytter og læring.

## Publiser på Vercel (5 minutter)

1. Gå til [github.com](https://github.com) og lag en gratis konto
2. Trykk **"New repository"**, gi den navnet `j11-trener`, trykk **Create**
3. Last opp **alle filene i denne mappen** til repositoryet
4. Gå til [vercel.com](https://vercel.com) og logg inn med GitHub
5. Trykk **"New Project"** → velg `j11-trener` → trykk **Deploy**
6. Etter ~1 minutt får du en lenke som `j11-trener.vercel.app` ✅

## Kjør lokalt (valgfritt)

```bash
npm install
npm run dev
```
